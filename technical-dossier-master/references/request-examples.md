# How to invoke

- `使用 technical-dossier-master，研究新加坡星耀樟宜的雨漩涡技术：重点是循环水、结构、防溅与CFD。给出可追溯原图的中文A4 PDF，并附证据表。`
- `Use technical-dossier-master to produce a source-verified English dossier on immersion cooling in data centres, comparing operating temperatures, pumping arrangements, serviceability and measured vs vendor-claimed efficiency. Include the evidence ledger.`
- `使用 technical-dossier-master，研究某型号锂离子电池热失控传播抑制方案，优先原始试验报告与标准，找不到的数据标为未知。`
- `使用 technical-dossier-master，只做资料查证和原始图纸收集，不生成PDF。`

# Optional specification
`行业/对象 | 核心技术问题 | 读者 | 语言 | 地域和年份 | 文档深度 | 强制资料类型 | 交付物`

Minimal request is sufficient; defaults cover missing settings.

## Bilingual example / 双语任务示例
「请使用 Technical Dossier Master 研究 Jewel Changi 的 Bouncing Net 和 Walking Net。我用中英混合交流。先访谈、再给中英双语大纲，等我批准后做中文主体、英文术语和双语图注的技术 PDF。查找水景资料时可读取既有 catalogue 目录，但不要将厂家参数当成该项目的实际施工数据。」
