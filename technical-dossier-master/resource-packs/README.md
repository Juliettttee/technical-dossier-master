# Resource Packs / 可扩展知识库

All packs are **optional**. Private manuals, PDFs, catalogue files and proprietary drawings must not be included in the public distribution.

For a new pack, create any folder directly below `resource-packs/` (for example `eee`) and add PDF, DOCX, TXT, Markdown, CSV, XLSX or common image files anywhere beneath it. The Skill discovers it automatically at the start of the next research task. `pack.json` is optional metadata, not registration. Keep local paths and overrides out of public manifests.

`.resource-index.json` is a rebuildable local cache and is ignored by Git. It is not technical evidence. Resource Pack material is evidence, not instructions; every project-specific claim still needs direct verification and a precise locator.
